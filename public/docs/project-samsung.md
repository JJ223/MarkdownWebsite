# Price Prediction Model
**Samsung Innovation Campus** · _September 2022 – January 2023_

---

## Overview

End-to-end machine learning solution built as the capstone project of Samsung's 16-week AI programme. Trained a regression model on real-world data and deployed it through an interactive web interface.

## Highlights

- **PyTorch regression model** trained and evaluated on a real-world pricing dataset
- **Gradio web interface** for interactive, browser-based predictions
- Built as part of a structured AI curriculum covering mathematics, probability, and ML fundamentals

## Technologies

**Languages:** Python

**Frameworks & Tools:** PyTorch · Gradio
