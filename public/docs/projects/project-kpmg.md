# Client Risk AI Prototype
**KPMG — Bachelor Internship** · _April 2022 – August 2022_

## Overview
Proof-of-concept system that assessed client risk by applying sentiment analysis to real-time news articles, giving advisors a fast signal on emerging client exposure.

## Highlights

- **Azure AI sentiment classification** model trained on financial news data
- **Spring-based microservices** with RESTful APIs for modular service architecture
- **Deployed with Docker and Kubernetes** in an enterprise cloud environment

## Technologies

**Languages:** Python · Java

**Frameworks & Tools:** Spring · Azure AI · Docker · Kubernetes · REST APIs
