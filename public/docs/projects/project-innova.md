# University Event Mobile App
**In-Nova** · _October 2022 – May 2023_

---

## Overview

Cross-platform mobile application built for a university-run event. Developed as part of NOVA FCT's student software projects initiative, working in a small team through the full product lifecycle.

## Highlights

- **Cross-platform mobile app** for iOS and Android built with React Native
- **Social networking features** — profiles, activity feeds, and real-time interactions
- **Firebase backend** for authentication, real-time database, and cloud functions
- Full lifecycle: planning, development, QA, and delivery

## Technologies

**Languages:** JavaScript · Java

**Frameworks & Tools:** React Native · Firebase · Google Cloud Platform
