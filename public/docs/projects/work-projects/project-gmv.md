# Autonomous Multi-Vehicle Mission Planner
**GMV — Master's Thesis** · _September 2023 – October 2024_

## Overview
Designed and built mission planning software for unmanned vehicles (USV, UAV, UGV) operating across multiple environments along Portugal's coastline. The system generates coordinated multi-vehicle mission plans under real operational constraints.

## Highlights

- **Hybrid optimisation algorithm** combining genetic algorithms and heuristic search to generate efficient multi-vehicle mission plans
- **RESTful HTTP API** to expose planning capabilities and support integration with external systems
- **Unity-based simulator** to validate plans and visualise vehicle coordination in realistic scenarios

## Technologies

**Languages:** C# · .NET

**Frameworks & Tools:** Unity · REST APIs · Genetic Algorithms · Heuristic Search
